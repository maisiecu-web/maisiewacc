# Maisie · WACC

An interactive, single-page live WACC model by Maisie Mary Cu.

The whole site is one self-contained file, `index.html`, served with GitHub Pages.

- **Live site:** https://maisiecu-web.github.io/maisiewacc/
- **To update:** replace `index.html` with a newer export and commit.

`.nojekyll` tells GitHub Pages to serve the file as-is, without a build step.
